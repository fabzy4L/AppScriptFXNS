# Shipdock Management Tools

A comprehensive set of scripts for managing Shipdock operations.

## Key Features
*   **Data Parsing**: `dbparser.gs.txt` for handling operational data.
*   **Operational Clearing**: Scripts to clear specific datasets:
    *   `staffing_clear.gs.txt`
    *   `schedule_clear.gs.txt`
    *   `role_clear.gs.txt`
    *   `foresight_clear.gs.txt`
*   **Formatting**: `format.gs.txt` for standardized reporting.
*   **Web Integration**: `open_web.gs.txt` for opening external operational links.
*   **Automation**: `macros.gs.txt` for repetitive tasks.
