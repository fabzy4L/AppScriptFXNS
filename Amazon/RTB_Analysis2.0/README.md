# RTB Analysis 2.0

A suite of tools for "Ready to Bill" (RTB) analysis, focused on data parsing and rate calculations.

## Components
*   **AR_Rates.gs.txt**: Handles rate calculations.
*   **DB Parser.gs.txt**: Extracts and processes data from external sources or internal sheets.
*   **DB Clear.gs.txt**: Utility to clear database sheets.
*   **RTBV3.0.gs.txt**: The main RTB analysis logic.
*   **Tabs.gs.txt**: Manages sheet navigation and tab structure.
*   **deleter.gs.txt**: Cleanup utility.
