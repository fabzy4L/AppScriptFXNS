# Operational Worksheet Tools

Scripts designed for the daily management and updating of operational worksheets.

## Key Features
*   **RTB Management**: `RTB.gs.txt` and `Update Form.gs.txt`.
*   **Data Snapshots**: `Snapshot.gs.txt` for capturing point-in-time data.
*   **Formatting**: `Eject Recirc Format.gs.txt` for specific operational data views.
*   **Maintenance**: `Hourly Clear.gs.txt`, `VRETS Clear.gs.txt`, and `Deleter.gs.txt`.
*   **Project Config**: `appsscript.json` manifest.
