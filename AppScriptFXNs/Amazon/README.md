# Amazon Operational Tools

This directory contains various Google Apps Script projects designed to automate and streamline operations within an Amazon logistics environment.

## Projects

*   **[Automated Thrive Generator](./Automated%20Thrive%20Generator)**: Scripts for generating Thrive-related reports.
*   **[RTB_Analysis2.0](./RTB_Analysis2.0)**: Tools for "Ready to Bill" (RTB) analysis and data parsing.
*   **[SHIPDOCK_MGMT_TOOLS](./SHIPDOCK_MGMT_TOOLS)**: A suite of tools for Shipdock management, including staffing, scheduling, and role management.
*   **[Worksheet](./Worksheet)**: Operational worksheet management, including snapshots and hourly updates.
